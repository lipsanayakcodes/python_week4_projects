# Employee Data Analysis Project

## About

This is a Python project that analyzes employee data using the Pandas library. It calculates average salary, counts employees by department, and filters employees based on salary.

## Technologies Used

* Python
* Pandas
* CSV

## Features

* Read employee data from a CSV file.
* Calculate average salary.
* Count employees in each department.
* Filter employees earning more than ₹50,000.
* Export filtered data to a new CSV file.
